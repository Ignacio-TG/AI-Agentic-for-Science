# Workshop de uso de agentes de IA para programación científica

Este taller está diseñado para introducir a personas al uso de **agentes de inteligencia artificial** en el desarrollo riguroso de tareas de programación científica.

La primera versión se desarrolló utilizando [Antigravity](https://antigravity.google/), y próximamente realizaremos versiones en [Claude Code](https://claude.com/es/product/claude-code) y [Codex](https://openai.com/es-419/codex/).

Desarrollado por M.Sc. Ignacio Tapia García y Prof. Felipe Huerta de la Pontificia Universidad Católica de Chile.
